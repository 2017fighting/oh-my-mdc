# ADR-0003: 两级聚合（任务=movie_id，版本=infohash），DB 是状态真相

- 状态：已接受（#7）
- 背景：PLAN.md「任务主键是番号」；但番号非唯一（合集、片商同名），且一个番号对应多磁力（普通/中字/破解）。
- 决策：任务按 movie_id 聚合（番号只是属性），版本按 infohash 独立走路；qbt 的 mdc:* tag 只作对账线索与人看标记，判定一律查 DB。失败不新增第三个 tag。
- 后果：刮削元数据一份、多版本共享（复用=0 网络）；对账简单（tag 只是发现入口）；tag 与 DB 不一致时以 DB 为准。规格见 §3/§6。
